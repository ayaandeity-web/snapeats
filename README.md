# SnapEats 🌱

Snap a photo of your food, get instant AI nutrition info, and grow a garden of pets by eating within your goal.

## What's inside
- `index.html` — page structure
- `style.css` — green theme, all styling
- `app.js` — Groq API calls, points system, pet shop logic (10 pets), local storage

## How it works
1. **Scan a meal** — take/upload a photo, or switch to "Homemade" and type your ingredients.
2. **AI analysis** — Groq's vision model (`qwen/qwen3.6-27b`) reads the photo or ingredient list and returns calories, protein, carbs, and fat as structured JSON.
3. **Points** — logging a meal at or under your calorie goal earns more points than logging one over it (everything earns something, so tracking is never punished).
4. **Pet shop** — spend points adopting any of 10 pets, from a 20-point Seedling up to a 400-point Dragon.

Everything (points, pets, history, your API key) is stored in your browser's `localStorage` — there's no backend/server, so it's free to host as a static site.

## Set up your Groq API key (built into the site)

This version ships with the key hardcoded into `app.js`, so visitors can use the site without pasting in their own key. Before you publish it, do these two things:

### 1. Put your key in the code
1. Go to https://console.groq.com/keys, sign in, click **Create API Key**, and copy it.
2. Open `app.js`, find this near the top:
   ```js
   const DEFAULT_GROQ_KEY = "PASTE_YOUR_GROQ_API_KEY_HERE";
   ```
3. Replace the placeholder text with your real key, keeping the quotes:
   ```js
   const DEFAULT_GROQ_KEY = "gsk_...yourrealkey...";
   ```

### 2. Limit your exposure in the Groq Console (important)
Groq doesn't currently offer HTTP-referrer key restrictions the way some other providers do, so the main protections available to you are usage limits and vigilance:

1. Go to https://console.groq.com/settings/limits (or the **Limits**/**Billing** section of the console) and set a spend limit or usage cap so the key can't run up unexpected costs.
2. Check https://console.groq.com/dashboard periodically for unusual spikes in usage.
3. If you ever suspect the key has been copied and misused, delete it from https://console.groq.com/keys and generate a new one (then update `app.js` and push the change).

Because this key lives in a public GitHub repo, anyone can view it in your published site's source code. This is a reasonable, standard level of protection for a static class/demo project — not a bulletproof one. For anything beyond a demo, the key should live on a small backend server instead of directly in client-side code.

**Visitors can still use their own key instead** — the Settings section has an optional field where anyone can paste their own Groq key, which overrides the built-in one in their browser only.

## Run it locally
No build step needed. Just open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Step-by-step: upload to GitHub

### 1. Create the repository
1. Go to https://github.com and log in.
2. Click the **+** in the top right → **New repository**.
3. Name it `snapeats`, leave it **Public**, don't add a README (you already have one), then click **Create repository**.

### 2. Install Git (if you don't have it)
- Windows: https://git-scm.com/download/win
- Mac: run `git --version` in Terminal — it'll prompt you to install if missing.

### 3. Push your files
Open a terminal in the folder containing `index.html`, `style.css`, `app.js`, and `README.md`, then run:

```bash
git init
git add .
git commit -m "Initial commit: SnapEats"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/snapeats.git
git push -u origin main
```

Replace `YOUR-USERNAME` with your actual GitHub username. GitHub may ask you to sign in or paste a personal access token instead of a password — if so, generate one at https://github.com/settings/tokens.

### 4. Turn it into a live website (GitHub Pages)
1. On your repo page, click **Settings**.
2. In the left sidebar, click **Pages**.
3. Under **Source**, choose **Deploy from a branch**, pick branch `main` and folder `/root`, then click **Save**.
4. Wait a minute, then refresh — GitHub will show your live URL, something like:
   `https://YOUR-USERNAME.github.io/snapeats/`

### 5. Making updates later
Whenever you change a file:

```bash
git add .
git commit -m "Describe what you changed"
git push
```

GitHub Pages redeploys automatically within a minute or two.

## Notes
- This app uses AI image recognition (Groq's vision model) as its core function, plus a recommender-style points/reward loop — it doesn't work without the AI step, since nutrition values are generated by the model rather than hardcoded.
- Nutrition estimates are AI-generated approximations, not medical or dietary advice.
